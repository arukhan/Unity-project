# Unity Final Project

A 3D game project built with Unity 6 (URP).

## Project Details
- **Unity Version**: 6000.0 (Unity 6)
- **Render Pipeline**: Universal Render Pipeline (URP)

## Project Structure
- `Assets/Scenes`: Game scenes and environments
- `Assets/Scripts`: Gameplay mechanics, player controls, and utilities
- `Assets/Settings`: URP rendering and quality profiles
